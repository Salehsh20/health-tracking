# HealthTrack 🏥

Hey! This is my simple health tracking app. I got tired of overcomplicated health apps, so I made this instead.

## What it does

Track your daily stuff:
- Activities (like "took vitamins" or "went for a walk")
- Meals and snacks
- Workouts
- See your progress

Nothing crazy, just the basics that actually matter.

## Why I built this

I wanted something simple that works in my browser without signing up for anything. Also needed to practice React, so win-win!

Built with React, JavaScript, and saves everything locally in your browser.

## How to run it

Need Node.js first, then:

```bash
git clone https://github.com/Salehsh20/health-tracking.git
cd health-tracking
npm install
npm start
```

Open `http://localhost:3000` and you're good to go.

## How to use it

Pretty straightforward - click around the nav bar (Home, Activities, Meals, Exercise, Progress). Everything saves automatically.

## Issues?

- Won't start? Make sure Node.js is installed and try `npm install` again
- Data gone? You probably cleared your browser storage
- Looks weird? Refresh the page
